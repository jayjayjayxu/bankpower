# 算力能源金融机会分析平台

`compute` 是与电力研究站并列的算力研究模块。算力设施、公开商品、能源效率、融资模型及算电协同代码均在本目录迭代；部署时通过同一入口的 `/compute/` 子路径访问，不影响电力研究根路径。

## 本地预览

```bash
cd frontend
npm install
npm run dev
```

浏览器使用终端显示的局域网地址访问，例如 `http://172.20.10.2:5174`。顶部“电力研究”默认跳转到本地电力站 `http://172.20.10.2:5173`，可在 `frontend/.env` 中通过 `VITE_POWER_SITE_URL` 修改。

## 当前页面

- 算力市场与银行研究逻辑；
- 公开设施、平台、商品和价格覆盖；
- H100、H800与昇腾商品价格口径展示；
- 五个重点算力设施画像；
- 算力—电力—融资连接流程；
- 保守、基准、乐观三档经营情景；
- 单变量敏感性、债务比例—DSCR融资曲线；
- 数学偿债能力与银行规则约束后的建议额度；
- 国家—广东—深圳—龙岗的算力政策规则库、设施适用性与训力券服务机构核验；
- 基于基准情景的算力业务机会清单，以及逐项政策/合同/能源/资产尽调任务；
- 商品—服务商/设施候选映射与公开披露融资结构案例；
- 数据口径、模型边界与尽调提示；
- 电力站与算力站的集成方案。
- 百旺信三期的“区域分时电价—绿电—储能—现金流代理”算电协同样本；需求响应在无注册、测试及结算证据时保持零收益。

当前首页已经连接本地Java接口。公开设施、商品与价格保持原披露口径；利用率、PUE、电价、CAPEX和信贷规则进入带有 `SCENARIO` 标识的研究情景表，不回填或覆盖公开事实表。银行建议额度仅表示是否值得进入尽调，不构成授信承诺。

银行规则层默认提供保守、基准和宽松三套研究情景。模型先计算数学DSCR容量，再同时施加最高债务比例、最低资本金、收入折扣、合格CAPEX比例和最低DSCR约束，因此不会把数学上可达的100%债务比例直接作为银行建议比例。

政策模块保存政策原文、可执行规则、公开服务机构名单与设施级初筛结果。它严格区分客户侧的训力券/购算力支持和设施侧的绿电、绿色数据中心、虚拟电厂与绿色金融机会；未取得项目级证据、申报或结算文件的支持不会计入NPV、IRR、DSCR或建议贷款额。

业务机会清单只筛选当前 `COMPUTE_BASE_V1 + CREDIT_BASE_V1` 下建议进入尽调的商品单元。若公开资料尚未确认实际设施、融资主体和资产权属，清单会将其列为阻断性事项，而不会将商品级测算伪装成已落地固定资产项目。

商品候选映射使用 `PUBLIC_INDICATIVE` 数据类型：同型GPU、平台专区和运营商设备部署只能形成服务商或设施候选，不会覆盖商品的实体设施外键。深圳百旺信智算中心则作为独立已核验设施入库；其公开融资案例仅用于结构设计参照，不回填算力商品的现金流或建议贷款额度。

详细集成边界见 [docs/POWER_COMPUTE_INTEGRATION.md](docs/POWER_COMPUTE_INTEGRATION.md)。

算电协同当前只对百旺信三期建立设施级结果：深圳2026年7月可匹配工商业分时电价作为区域成本压力情景，深圳本地清洁电源装机与广东发电结构仅作供给背景；20%绿电采购与2%储能移峰均明确标识为研究情景，不替代该项目实际账单、绿电合同、工程设计、需求响应收益、CFADS或授信结论。

## 本地Docker端口

- 前端：`http://<本机局域网IP>:8084`
- 后端：`http://<本机局域网IP>:8082`

这些端口与电力项目错开，便于两个项目同时运行。

## 服务器同域访问

生产环境不依赖域名，使用服务器 IP 的同域入口：电力研究在 `/`，工作台在 `/bank-workbench`，算力研究在 `/compute/`。算力页面接口前缀为 `/compute/api/`，电力页中的“算力研究”入口与算力页中的“电力研究 / 工作台”入口均保持同域跳转。
