# 算力公开数据初始化包

本目录用于向已有的 `spdb_power_finance` 数据库**增量**写入算力模块的公开事实数据；不会清空或替换电力侧数据。

初始化顺序如下：

1. 运行 `24_compute_infrastructure_v1.py --execute`，创建基础设施、平台、字段证据等基础表，并写入 15 个公开设施和 5 个平台。
2. 运行 `25_compute_platform_snapshot_v1.py --execute`，从 `sources/compute/2026-08-25` 的已留存 JSON 快照写入公开商品及价格。
3. 按 `backend/sql/` 中的依赖顺序运行模型、信贷规则、候选映射、政策、机会、百旺信与算电协同 SQL。

原始平台 JSON 与明细价格均作为 2026-08-25 的公开快照保存。列表参考价与详情配置价会分别入库；两者冲突时不会相互覆盖。
